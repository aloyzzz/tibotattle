# Documentation

Current documentation for TiboTattle 0.2.x (omp edition). Code and tests are
the authority on implemented behavior; these pages describe the intended
contracts and must be updated in the same change when a contract moves.

| [reference/macos-app.md](reference/macos-app.md) | Native macOS menu-bar app: shape, compatibility with the Node index, Swift API |
